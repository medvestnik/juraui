Why Jura UI

Built for real admin work

Everything you need to ship admin interfaces quickly, without the overhead of large frameworks.

Lightweight

Under 8 KB of CSS. No runtime, no bundler, no Node.js required to use it.

Framework agnostic

Works with plain HTML, Laravel Blade, Twig, PHP, Django, Rails — any backend.

Admin-first

Designed for CRUD interfaces, data tables, forms and dashboards — not marketing sites.

7 colour themes

Switch themes with one attribute. Indigo, Ocean, Emerald, Rose, Violet, Amber or Slate.

CSS-variable tokens

All colours, radii and shadows exposed as CSS custom properties for easy override.

MIT & open source

Free for personal and commercial use. Hosted on GitHub, contributions welcome.

Quick start

One line to get started

Drop a stylesheet link into your HTML. No npm, no build step, no configuration.

<link rel="stylesheet"
      href="https://medvestnik.github.io/juraui/assets/css/jura-ui.css">

<!-- Apply a colour theme -->
<html data-jura-theme="ocean">

<!-- Use it -->
<button class="jura-btn jura-btn-primary">Get started</button>
